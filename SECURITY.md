# Security Policy

## Project status

Health is in its initial planning phase. There are no supported versions or
production releases.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull
request, log, or screenshot.

Use GitHub's
[private vulnerability reporting](https://github.com/xpelch/health/security/advisories/new)
to send the repository owner a private report. Include:

- a concise description of the issue and its impact;
- the affected platform or component;
- reproduction steps or a minimal proof of concept;
- any relevant configuration with secrets and personal data removed;
- suggested remediation, if known.

The maintainer will use the private advisory to acknowledge the report,
investigate it, and coordinate any disclosure. A response or resolution
timeline is not guaranteed while the project has no supported release.
